# SauceDemo E-commerce Website — Manual QA Testing

## Overview
Beginner manual QA portfolio project documenting functional testing of the SauceDemo demonstration e-commerce application.

## Contents
- `01-Test-Plan/Test-Plan.pdf`
- `02-Test-Cases/Test-Cases.xlsx` — 15 test cases
- `03-Test-Evidence/` — folders for original screenshots
- `04-Bug-Reports/Bug-Reports.xlsx`
- `05-Test-Summary/Test-Summary.pdf`

## Important accuracy note
TC-001 through TC-009 are recorded as PASS based on user-reported results or screenshots in the working session. TC-010 through TC-015 are **inferred, not verified**. They were populated with likely behavior at the user's request, not from observed execution. Do not claim these six cases were executed or passed. Run them, record actual results and add evidence before publishing a fully executed report.

## Next steps
